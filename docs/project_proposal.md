# 차대차 사고 영상 기반 과실비율 설명 멀티모달 챗봇 연구계획서

## 1. 연구 주제

차대차 사고 영상을 입력으로 받아 사고 상황을 이해하고, 과실비율 판단에 도움이 되는 근거를 추출하여 사용자에게 설명 가능한 형태로 응답하는 멀티모달 챗봇을 설계하고 구현한다.

---

## 2. 연구 배경 및 필요성

교통사고 발생 시 블랙박스나 사고 영상은 사고 원인과 과실 판단의 핵심 자료로 활용된다.  
그러나 일반 사용자는 영상을 보고도 어떤 장면이 중요한지, 어떤 근거가 과실 판단에 영향을 주는지 즉시 이해하기 어렵다.  
또한 사고 장면 분석은 단순 영상 분류를 넘어 시간 흐름, 차량 위치 관계, 진입 방향, 정차 여부, 차선 변경 여부 등 복합적인 요소를 함께 고려해야 한다.

따라서 본 연구는 사고 영상을 기반으로 주요 사건을 구조화하고, 그 결과를 자연어로 설명하는 멀티모달 챗봇을 통해 사용자가 사고 상황을 이해하는 데 도움을 주는 시스템을 제안한다.

---

## 3. 문제 정의

본 연구에서 해결하고자 하는 핵심 문제는 다음과 같다.

1. 차대차 사고 영상을 입력으로 받아 사고 관련 핵심 장면을 이해할 수 있어야 한다.
2. 영상으로부터 과실 판단에 영향을 줄 수 있는 근거를 추출할 수 있어야 한다.
3. 추출된 근거를 바탕으로 사용자에게 설명 가능한 응답을 생성할 수 있어야 한다.
4. 제한된 기간과 자원 안에서 동작 가능한 MVP 수준의 시스템을 구현해야 한다.

---

## 4. 연구 목표

본 연구의 목표는 다음과 같다.

- 차대차 사고 영상 기반 멀티모달 챗봇 프로토타입 구현
- 사고 영상에서 핵심 사건 및 판단 근거 추출
- 과실비율 판단에 도움이 되는 설명형 응답 생성
- 서브셋 기반 경량 데이터 파이프라인 구축
- 추후 백엔드/프론트엔드 연동이 가능한 구조 설계

## 6. 데이터셋 개요

본 연구는 다음 데이터셋을 사용한다.

- Public URL: `https://data.taeo-dev.com/dataset/traffic`
- Local Path: `/volume1/project/dataset/traffic`

### 디렉터리 구조
```text
traffic/
  1.Training/
    label_data_231108_add/
    raw_data_231108_add/
  2.Validation/
    label_data_231108_add/
    raw_data_231108_add/
```

### 확인된 데이터 특성
- Training 원천데이터: 약 2.7TB
- Training 라벨데이터: 약 2.8GB
- Validation 원천데이터: 약 341GB
- Validation 라벨데이터: 약 359MB
- 영상 샘플 수: 14,099개
- JSON 샘플 수: 14,099개
- 영상 파일과 JSON 파일은 basename 기준 1:1 매칭 구조

### 1차 활용 범위
초기 연구에서는 아래만 활용한다.

- `TS_차대차_영상_*.zip`
- `TL_차대차_영상_*.zip`

즉, 이미지 ZIP은 제외하고 영상+JSON 라벨만 사용한다.

## 7. 데이터 전처리 및 서브셋 전략

전체 데이터를 바로 사용하는 대신, 초기에는 목적에 맞는 서브셋을 구성한다.

### 7.1 Validation 사용 원칙
- `2.Validation`은 최종 홀드아웃 검증셋으로 유지한다.
- 실제 subset 생성은 `1.Training` 내부에서만 수행한다.

### 7.2 파이프라인 검증용 subset
목적:
- ZIP 인덱싱 검증
- 영상/JSON 1:1 매칭 검증
- 프레임 샘플링 검증
- 추론 입력/출력 구조 검증

기준:
- 카테고리별 10개
- 총 80개 샘플

### 7.3 MVP subset
목적:
- 데모 품질 확보
- 프롬프트 조정
- 추론 로직 검증
- 오류 유형 분석

기준:
- 카테고리별 70~100개
- 총 600~800개 샘플

### 7.4 확장 subset
목적:
- 성능이 약한 카테고리 보강
- 오류 케이스 추가 분석

기준:
- MVP 이후 필요한 카테고리만 추가
- 총합 1,200~1,600개 수준까지 단계적 확장 가능

### 7.5 샘플링 원칙
- 용량 비례 샘플링이 아닌 카테고리 균형 샘플링 사용
- 영상과 JSON은 basename 기준 매칭
- 초기 단계에서는 원본 mp4 1개를 샘플 1개로 사용
- subset은 폴더 복사 방식이 아니라 manifest 기반으로 관리

## 8. 데이터셋 카테고리

현재 영상 ZIP은 다음 8개 카테고리로 구성된다.

- 회전교차로
- 차도와 차도가 아닌 장소
- 주차장(또는 차도가 아닌 장소)
- 고속도로(자동차전용도로 포함)
- T자형교차로
- 사거리교차로(신호등 없음)
- 사거리교차로(신호등 있음)
- 직선도로

카테고리 간 사고 양상과 판단 난이도가 다르므로, 초기 서브셋은 각 카테고리를 고르게 반영하도록 구성한다.

## 9. 연구 방법 및 시스템 설계

본 연구는 멀티모달 입력을 처리하는 구조를 기반으로 다음과 같은 파이프라인을 설계한다.

### 9.1 전체 흐름
1. 영상 입력
2. 영상 프레임 샘플링
3. 멀티모달 모델을 통한 사건 이해
4. 사고 근거 구조화
5. 자연어 설명 생성
6. 사용자 응답 반환

### 9.2 핵심 아이디어
본 연구는 영상만 보고 단순히 과실비율을 직접 출력하는 방식보다, 아래 두 단계를 거치는 구조를 채택한다.

#### 1단계: 사건 추출
- 사고 장면 핵심 이벤트 파악
- 차량 위치/진입/정차/충돌 상황 파악
- 판단 근거 후보 추출

#### 2단계: 설명 생성
- 추출된 사건을 바탕으로 응답 생성
- 사용자에게 이해 가능한 문장으로 설명
- 불확실한 요소는 불확실성으로 명시

이 구조는 단순 결과 출력보다 설명 가능성이 높고, 오류 분석에도 유리하다.

## 18. 결론

본 연구는 차대차 사고 영상을 기반으로 사고 상황을 이해하고, 과실비율 판단에 도움이 되는 근거를 사용자에게 설명하는 멀티모달 챗봇을 목표로 한다.

전체 대용량 데이터를 그대로 사용하는 대신, 영상 중심 subset 전략과 manifest 기반 데이터 관리를 통해 짧은 기간 안에 실현 가능한 MVP를 구축한다.  
이를 통해 사고 영상 이해와 설명 생성이 결합된 멀티모달 챗봇의 구현 가능성을 검증하고, 향후 서비스형 구조로 확장 가능한 기반을 마련하고자 한다.
